# Plataforma LMS de Desenvolvimento

Este repositório recebeu a branch `lms-desenvolvimento` para continuidade do protótipo da plataforma LMS.

## Link público

https://lms-desenvolvimento.bkp3hudson.chatgpt.site

O acesso do site foi alterado para público, então qualquer pessoa com o link consegue abrir.

## Estado do protótipo

- Plataforma LMS navegável para venda como solução de consultoria em desenvolvimento.
- Áreas separadas para colaborador, gestor e administração.
- Menus laterais habilitados.
- Trilhas, conteúdos independentes, favoritos, conquistas, relatórios, equipe, biblioteca, usuários, configurações, integrações e suporte.
- Todos os botões principais do protótipo respondem com página, drawer, toast ou alteração visual.
- Trilhas mostram módulos e conteúdos internos.
- Filtros da tela de conteúdos funcionam.
- Gestor possui trilha de liderança e biblioteca própria.
